# Cálculos e Conversões

Exercícios práticos de cálculos matemáticos, conversão de tipos e calculadoras em Python, parte do curso da [Alura](https://www.alura.com.br/).

## 📂 Exercícios

- **calcula_ano.py** — Cálculo relacionado a datas/anos
- **calcula_gorjeta.py** — Cálculo de gorjeta sobre um valor de conta
- **calculado_simples.py** — Calculadora simples com operações básicas (+, -, *, /) e tratamento de erros
- **calculadora_com_lambda.py** — Calculadora usando funções `lambda`
- **calculo_média.py** — Cálculo de média de valores
- **calculo_total_vendas.py** — Soma o total de vendas a partir de valores digitados pelo usuário, com validação de entradas
- **conversor_tipos.py** — Conversão entre tipos de dados (`int`, `float`, `str`, etc.)
- **desconto_fixo.py** — Cálculo de desconto sobre um valor

## 🧠 Conceitos praticados

- Operações aritméticas e conversão entre tipos numéricos
- Funções `lambda` para operações simples
- Tratamento de exceções (`try/except`) para entradas inválidas
- Formatação de números (casas decimais, moeda)

## 🛠️ Tecnologias

- Python 3

## ▶️ Como executar

```bash
python nome_do_arquivo.py
```
