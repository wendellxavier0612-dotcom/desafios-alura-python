# Listas e Coleções

Exercícios práticos de manipulação de listas em Python, parte do curso da [Alura](https://www.alura.com.br/).

## 📂 Exercícios

- **correção_posições.py** — Correção/ajuste de posições de itens em uma lista
- **filtra_pares.py** — Filtra os números pares de uma lista
- **juntar_listas.py** — Junção de duas ou mais listas
- **ordenando_eventos.py** — Ordenação de uma lista de eventos
- **organizando_notas.py** — Organização de uma lista de notas
- **reorganizar_lista.py** — Reorganização de itens dentro de uma lista
- **retirando_ultimo_item.py** — Remoção do último item de uma lista
- **verificar_itens.py** — Verificação/validação de itens presentes em uma lista

## 🧠 Conceitos praticados

- Indexação e fatiamento (*slicing*) de listas
- Métodos de lista: `.append()`, `.sort()`, `.pop()`, `.remove()`
- Laços de repetição (`for`) para percorrer e filtrar listas
- List comprehension para criar listas de forma concisa

## 🛠️ Tecnologias

- Python 3

## ▶️ Como executar

```bash
python nome_do_arquivo.py
```
