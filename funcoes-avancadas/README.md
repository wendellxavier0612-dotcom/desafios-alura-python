# Funções Avançadas

Exercícios de recursão e geração de dados aleatórios em Python, parte do curso da [Alura](https://www.alura.com.br/).

## 📂 Exercícios

- **recursiva.py** — Exemplos de funções recursivas
- **gerador_senha_segura.py** — Gerador de senhas seguras com caracteres aleatórios

## 🧠 Conceitos praticados

- Recursão: funções que chamam a si mesmas e condição de parada (caso base)
- Geração de valores aleatórios (módulo `random`)
- Boas práticas de segurança na criação de senhas (mistura de letras, números e símbolos)

## 🛠️ Tecnologias

- Python 3
- Módulo `random`

## ▶️ Como executar

```bash
python nome_do_arquivo.py
```
