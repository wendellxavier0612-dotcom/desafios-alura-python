# Desafios Alura - Python

Repositório com pequenos projetos e exercícios desenvolvidos durante meus estudos de Python na [Alura](https://www.alura.com.br/), cobrindo desde lógica básica até estruturas de dados, funções avançadas e pequenos sistemas simulados.

## 📂 Projetos

### 🔢 Cálculos e conversões
- **calcula_ano.py** — Cálculo relacionado a datas/anos
- **calcula_gorjeta.py** — Cálculo de gorjeta
- **calculado_simples.py** — Calculadora simples com operações básicas
- **calculadora_com_lambda.py** — Calculadora usando funções `lambda`
- **calculo_média.py** — Cálculo de média de valores
- **calculo_total_vendas.py** — Cálculo do total de vendas
- **conversor_tipos.py** — Conversão entre tipos de dados
- **desconto_fixo.py** — Cálculo de desconto sobre um valor

### 🔤 Manipulação de texto
- **calcula_caracteres.py** — Contagem de caracteres em texto
- **contagem_vogais.py** — Contador de vogais em uma string
- **identificador_palavras_longas.py** — Identifica palavras longas em um texto
- **saudação_personalizada.py** — Saudação personalizada por nome

### 📋 Listas e coleções
- **correção_posições.py** — Correção/ajuste de posições em uma lista
- **filtra_pares.py** — Filtro de números pares em uma lista
- **juntar_listas.py** — Junção de listas
- **ordenando_eventos.py** — Ordenação de eventos
- **organizando_notas.py** — Organização de notas
- **reorganizar_lista.py** — Reorganização de itens em uma lista
- **retirando_ultimo_item.py** — Remoção do último item de uma estrutura
- **verificar_itens.py** — Verificação/validação de itens em uma coleção

### 🗂️ Pequenos sistemas / registros
- **gerenciador_de_tarefas.py** — Sistema simples de gerenciamento de tarefas
- **registro_dados.py** — Registro de dados
- **registro_voluntarios.py** — Cadastro de voluntários
- **relatorio_estoque.py** — Relatório de controle de estoque
- **sistema_cédulas_únicas.py** — Sistema de contagem de cédulas
- **validador_de_cpf.py** — Validador de CPF

### 🎮 Jogos
- **jogo_numero_secreto.py** — Jogo de adivinhação de número secreto
- **pedra_papel_tesoura.py** — Jogo Pedra, Papel e Tesoura

### 🔁 Funções avançadas
- **recursiva.py** — Exemplos de funções recursivas
- **gerador_senha_segura.py** — Gerador de senhas seguras

## 🛠️ Tecnologias

- Python 3
