# Manipulação de Texto

Exercícios práticos de análise e manipulação de strings em Python, parte do curso da [Alura](https://www.alura.com.br/).

## 📂 Exercícios

- **calcula_caracteres.py** — Contagem de caracteres em um texto
- **contagem_vogais.py** — Contador de vogais em uma string
- **identificador_palavras_longas.py** — Identifica palavras longas em um texto
- **saudação_personalizada.py** — Monta uma saudação personalizada por nome

## 🧠 Conceitos praticados

- Iteração sobre strings caractere a caractere
- Métodos de string (`.split()`, `.lower()`, `.upper()`, `len()`)
- Contadores e acumuladores
- f-strings para formatação de saída

## 🛠️ Tecnologias

- Python 3

## ▶️ Como executar

```bash
python nome_do_arquivo.py
```
