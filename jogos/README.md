# Jogos

Jogos simples em terminal desenvolvidos em Python, parte do curso da [Alura](https://www.alura.com.br/).

## 📂 Exercícios

- **jogo_numero_secreto.py** — Jogo de adivinhação de número secreto
- **pedra_papel_tesoura.py** — Jogo Pedra, Papel e Tesoura contra o computador

## 🧠 Conceitos praticados

- Geração de números aleatórios (módulo `random`)
- Estruturas condicionais (`if/elif/else`) para definir regras do jogo
- Laços de repetição para permitir múltiplas tentativas/rodadas
- Interação com o usuário via `input()`

## 🛠️ Tecnologias

- Python 3
- Módulo `random`

## ▶️ Como executar

```bash
python nome_do_arquivo.py
```
