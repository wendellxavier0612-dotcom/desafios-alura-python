# Sistemas e Registros

Pequenos sistemas de terminal e validadores desenvolvidos em Python, parte do curso da [Alura](https://www.alura.com.br/).

## 📂 Exercícios

- **gerenciador_de_tarefas.py** — Sistema simples de gerenciamento de tarefas
- **registro_dados.py** — Registro de dados informados pelo usuário
- **registro_voluntarios.py** — Cadastro de voluntários
- **relatorio_estoque.py** — Geração de relatório de controle de estoque
- **sistema_cédulas_únicas.py** — Sistema de contagem de cédulas
- **validador_de_cpf.py** — Validação de número de CPF

## 🧠 Conceitos praticados

- Estruturas de dados (listas, dicionários) para armazenar registros
- Menus interativos via terminal com laços de repetição
- Validação de entradas do usuário
- Funções para organizar e reutilizar lógica

## 🛠️ Tecnologias

- Python 3

## ▶️ Como executar

```bash
python nome_do_arquivo.py
```
